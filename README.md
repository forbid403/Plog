# Plog

## Running on the iOS Simulator

- A fresh or erased simulator has **no location**, so anything that needs GPS (Home weather, Plog recording) fails — Home shows `Weather unavailable`. Set one from the simulator menu: **Features → Location → Custom Location** (e.g. Surry Hills `-33.8886, 151.2094`), or **City Run** to simulate moving. Then leave and re-enter the screen.
